# MMU：多模态大模型遗忘评测（阶段汇总）

在线页面：https://gitdrowner.github.io/MMU/

研究对象是 LLaVA-1.5-7B 在 MLLMU-Bench 上的五种遗忘方法（遗忘 5% 的人物）。要回答的问题是：被"遗忘"的人物知识是真的没了，还是换个条件就能拿出来。所有结论都相对 Oracle 而言，Oracle 是一个从未见过这些人物的参照模型。

页面汇总了三轮实验：

1. **四组重学对照**：在无关数据上微调，能否恢复遗忘人物的知识。
2. **推理路径审计**：让模型先写一段推理，会不会多暴露知识。
3. **utility 约束下的恢复**：在 retain 准确率下降不超过 2、5、10 个点的条件下，无关数据上的更新能否让遗忘模型比 Oracle 暴露更多知识。

证据范围：一个模型、一个数据划分、一个随机种子。

这个仓库目前只包含汇总页面（`index.html`）和页面用到的图（`assets/`），不含实验代码、模型和逐题结果。
